# 👟 Shoe Store Management System

A C# Windows Forms desktop application built to manage daily shoe store operations including product catalogs, sales invoicing, and inventory tracking.

## 📌 Features

- **Product & Category Management:** Add, edit, and search shoe models with category classification.
- **Order & Invoicing:** Select items, calculate totals, and process sales invoices.
- **Inventory Tracking:** Automatically update stock quantities upon order completion.
- **Customer Directory:** Store customer info and view order histories.

---

## 🛠️ Tech Stack & Architecture

- **Language & Framework:** C# (.NET Framework), WinForms
- **UI Components:** DotNetBar
- **Database:** Microsoft SQL Server
- **Architecture:** 3-Tier Architecture separating UI, Business Logic (BUS), and Data Access (DAO/DTO).
